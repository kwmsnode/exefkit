# EX拡張フォントキット
## 概要
EX拡張文字表示ライブラリをパワーアップ。フォント関連機能続々追加。EX-wordにお好みのフォントを表示しよう。
## 使用方法など
[ホームページ](https://kwmsnode.f5.si/projects/exefkit)に記載しています。
